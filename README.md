# Burgos Tacos · carta digital

Carta de French Tacos con un vídeo por taco («lo que lleva»). Web pública: https://burgos-tacos.vercel.app (es la dirección del QR de la carta impresa).

- `index.html` — la carta (una sola página, fuentes incrustadas).
- `fotos/` — fotos ilustrativas de los 11 tacos.
- `videos/` — un vídeo vertical (1080 × 1920) por taco.
- `posters/` — fotograma que se ve mientras carga cada vídeo.

Vercel publica el contenido de la rama `main` en burgos-tacos.vercel.app. Para cambiar un precio o un vídeo: edita `index.html` o sustituye el archivo con el mismo nombre y vuelve a publicar.
